# Memory Contract — Validation Rules (VAL-073 – VAL-084)

Governs: [`memory.contract.md`](../contracts/memory.contract.md) · Schemas: [`memory.schema.yaml`](../schemas/memory.schema.yaml), [`memory.schema.json`](../schemas/memory.schema.json)

| ID      | Rule                                                                                                                                                                                                                             | Severity | Governing Source           |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | -------------------------- |
| VAL-073 | Every tier's `ownership.tenant_id` MUST be a non-null UUID; a memory query resolving a null tenant is rejected.                                                                                                                  | Blocking | Constitution §13.2         |
| VAL-074 | Every tier's `ownership.entity_id` MUST be a non-empty string namespacing the write to a lead/conversation/customer/tenant/agent.                                                                                                | Blocking | Constitution §13.3         |
| VAL-075 | `access_gateway` MUST be non-empty; no Agent or Tool may declare a direct store connection in place of the gateway reference.                                                                                                    | Blocking | Architecture §20           |
| VAL-076 | `working_memory.ttl` and `session_memory.ttl` MUST both be present (ephemeral tiers never persist indefinitely by default).                                                                                                      | Blocking | Constitution §13.3         |
| VAL-077 | `long_term_memory.retention_policy` and `semantic_memory.retention_policy` MUST both be present (durable tiers require an explicit retention/expiry action).                                                                     | Blocking | Constitution §13.3         |
| VAL-078 | Any tier or the top-level `pii_policy` with `contains_pii = true` MUST set `erasure_cascade_required = true`.                                                                                                                    | Blocking | DDD BR-109                 |
| VAL-079 | `vector_memory.embedding_model_version` MUST be present and MUST resolve to a published Model Contract entry.                                                                                                                    | Blocking | Architecture §20           |
| VAL-080 | `vector_memory.dimensions`, if present, MUST match the declared `embedding_model`'s published output dimensionality.                                                                                                             | Blocking | Model Contract cross-check |
| VAL-081 | `retention_policy.duration` and any tier's `retention_policy.duration` MUST be a valid ISO 8601 duration expression.                                                                                                             | Blocking | Schema constraint          |
| VAL-082 | `status = active` REQUIRES `working_memory`, `session_memory`, `long_term_memory`, `semantic_memory`, and `vector_memory` to all have `enabled = true` or an explicit documented reason in `metadata` for any that are disabled. | Warning  | Domain judgment call       |
| VAL-083 | `cache`, if present, MUST NOT be the sole store for any tier flagged `contains_pii = true` (cache is non-authoritative and may not honor retention/erasure guarantees).                                                          | Blocking | Constitution §13.5         |
| VAL-084 | `code` MUST be unique per tenant scope within the Memory Registry sub-registry.                                                                                                                                                  | Blocking | Registry Contract §1       |
