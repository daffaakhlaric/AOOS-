# Knowledge Contract — Validation Rules (VAL-085 – VAL-096)

Governs: [`knowledge.contract.md`](../contracts/knowledge.contract.md) · Schemas: [`knowledge.schema.yaml`](../schemas/knowledge.schema.yaml), [`knowledge.schema.json`](../schemas/knowledge.schema.json)

| ID      | Rule                                                                                                                                                                                                  | Severity | Governing Source                    |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------------- |
| VAL-085 | `lifecycle` MUST be one of `ingested`, `indexed`, `active`, `stale`, `archived`, and MUST only regress via `stale → active`.                                                                          | Blocking | Architecture §21 Sequence           |
| VAL-086 | `confidence` MUST be a number between 0.0 and 1.0 inclusive.                                                                                                                                          | Blocking | Schema constraint                   |
| VAL-087 | `embedding` MUST be present before `lifecycle` transitions to `indexed` or `active`.                                                                                                                  | Blocking | Architecture §21                    |
| VAL-088 | `version` MUST NOT be mutated once `lifecycle = active`; content changes require a new instance with an incremented `version`.                                                                        | Blocking | Knowledge Contract §4 (append-only) |
| VAL-089 | `customer_facing = true` entries whose `last_synced_at` exceeds `max_staleness_sla` MUST be excluded from pricing/inventory-claim retrieval regardless of a lagging `lifecycle = active` cache value. | Blocking | DDD BR-094                          |
| VAL-090 | `source_citation` MUST be a non-empty string.                                                                                                                                                         | Blocking | Architecture §21 Best Practice      |
| VAL-091 | `knowledge_source.type = structured_catalog` REQUIRES `document.format` to be one of `json`, `csv`.                                                                                                   | Blocking | Domain judgment call                |
| VAL-092 | `ownership.scope = tenant` REQUIRES `ownership.tenant_id` to be non-null; `scope = global` REQUIRES `tenant_id` to be null.                                                                           | Blocking | Knowledge Contract §4               |
| VAL-093 | `max_staleness_sla` MUST be a valid ISO 8601 duration expression.                                                                                                                                     | Blocking | Schema constraint                   |
| VAL-094 | `lifecycle = archived` entries MUST NOT be referenced by any `active`-state Agent's `knowledge[]` array.                                                                                              | Warning  | Registry Contract cross-check       |
| VAL-095 | `embedding.dimensions`, if present, MUST be a positive integer matching the declared `embedding.model`'s published output dimensionality.                                                             | Blocking | Model Contract cross-check          |
| VAL-096 | `title` MUST be unique within the same `ownership.tenant_id` + `knowledge_source.type` combination.                                                                                                   | Warning  | Domain judgment call                |
