# Tool Contract — Validation Rules (VAL-013 – VAL-024)

Governs: [`tool.contract.md`](../contracts/tool.contract.md) · Schemas: [`tool.schema.yaml`](../schemas/tool.schema.yaml), [`tool.schema.json`](../schemas/tool.schema.json)

| ID      | Rule                                                                                                                                                                                                                | Severity | Governing Source             |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ---------------------------- |
| VAL-013 | `tool_id` MUST match `^tool\.[a-z][a-z0-9_]*$` and MUST NOT change across versions of the same Tool.                                                                                                                | Blocking | Tool Contract §1             |
| VAL-014 | Every Tool MUST declare `side_effect_class` as one of `read-only`, `reversible-write`, `irreversible-write`.                                                                                                        | Blocking | Constitution RULE-007, §12.3 |
| VAL-015 | If `side_effect_class = irreversible-write`, `authorization.requires_policy_approval` MUST be `true`.                                                                                                               | Blocking | Constitution §12.3, RULE-007 |
| VAL-016 | If `side_effect_class = irreversible-write`, `compensation` MUST be non-null.                                                                                                                                       | Blocking | Constitution RULE-028        |
| VAL-017 | `retry.idempotency_key_param` MUST name a parameter present in the Tool's `input_schema`.                                                                                                                           | Blocking | Constitution §12.4, RULE-004 |
| VAL-018 | `permission_scope` MUST contain at least one entry.                                                                                                                                                                 | Blocking | Tool Contract §4             |
| VAL-019 | `authentication.secret_ref` MUST be non-empty and MUST resolve via the Secrets Manager before `status` may be `active`.                                                                                             | Blocking | Constitution §12.6, RULE-060 |
| VAL-020 | If `side_effect_class = reversible-write`, either `rollback.supported = true` or `compensation` MUST be non-null.                                                                                                   | Blocking | Constitution RULE-028        |
| VAL-021 | `circuit_breaker.failure_threshold` MUST be ≥ 1.                                                                                                                                                                    | Blocking | Constitution §12.5           |
| VAL-022 | If `side_effect_class = read-only`, both `rollback` and `compensation` MUST be `null`.                                                                                                                              | Warning  | Tool Contract §4             |
| VAL-023 | Every Tool call MUST be logged with input (PII-redacted), output, latency, cost, and success/failure — `telemetry.pii_redaction` MUST be `true` for any Tool whose `input_schema` or `output_schema` may carry PII. | Blocking | Constitution §12.7, §17      |
| VAL-024 | `version` MUST follow strict SemVer (`MAJOR.MINOR.PATCH`).                                                                                                                                                          | Blocking | Constitution RULE-070        |
