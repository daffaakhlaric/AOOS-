# Logging Contract — Validation Rules (VAL-181 – VAL-192)

Governs: [`logging.contract.md`](../contracts/logging.contract.md) · Schemas: [`logging.schema.yaml`](../schemas/logging.schema.yaml), [`logging.schema.json`](../schemas/logging.schema.json)

| ID      | Rule                                                                                                                                                                                                                              | Severity | Governing Source          |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ------------------------- |
| VAL-181 | `log_id`, `trace_id`, `span_id`, `tenant_id`, `emitting_component`, `severity`, `timestamp`, `message`, `pii_redacted`, `retention_class` MUST all be present on every log record.                                                | Blocking | Constitution RULE-045     |
| VAL-182 | `severity` MUST be exactly one of `DEBUG`, `INFO`, `WARN`, `ERROR`, `CRITICAL`.                                                                                                                                                   | Blocking | Constitution §17.3        |
| VAL-183 | `tenant_id` MUST be non-empty; `"platform"` is the only accepted value for genuinely tenant-less system logs.                                                                                                                     | Blocking | Constitution RULE-045     |
| VAL-184 | `metadata` and `context` MUST NOT contain plaintext PII (phone, email, address, payment reference); `pii_redacted` MUST be `true` before shipping.                                                                                | Blocking | Constitution RULE-046     |
| VAL-185 | `severity = DEBUG` records MUST carry `retention_class = ephemeral_debug`.                                                                                                                                                        | Blocking | Logging Contract §4       |
| VAL-186 | `severity = CRITICAL` records MUST have `alert_dispatched = true` within the paging SLA window.                                                                                                                                   | Blocking | Constitution §17.3        |
| VAL-187 | If `emitting_component` is an Agent and the record documents a model-backed decision, `context.prompt_version`, `context.model`, and `context.confidence` MUST all be populated.                                                  | Blocking | Constitution §17.4        |
| VAL-188 | `context.confidence`, when present, MUST be between 0 and 1 inclusive.                                                                                                                                                            | Blocking | Schema constraint         |
| VAL-189 | A shipped log record MUST NOT be mutated in place; corrections are appended as new records sharing the same `trace_id`.                                                                                                           | Blocking | Logging Contract §3       |
| VAL-190 | `trace_id` MUST correlate with an active or completed distributed trace span (Constitution §25.2); an orphaned `trace_id` with no corresponding trace is a Warning, not auto-rejected (log ingestion may race trace propagation). | Warning  | Constitution §25.2        |
| VAL-191 | `message` MUST be a human-readable summary, not a raw concatenation of variable data best carried in `metadata`.                                                                                                                  | Warning  | Constitution §17.1        |
| VAL-192 | `retention_class = extended_compliance` SHOULD be used for logs touching PII-adjacent categories (SPK, Quotation, Delivery) even after redaction, to satisfy compliance audit trail duration.                                     | Warning  | Constitution §17.5, §20.7 |
