# Scheduler Contract — Validation Rules (VAL-121 – VAL-132)

Governs: [`scheduler.contract.md`](../contracts/scheduler.contract.md) · Schemas: [`scheduler.schema.yaml`](../schemas/scheduler.schema.yaml), [`scheduler.schema.json`](../schemas/scheduler.schema.json)

| ID      | Rule                                                                                                                                                                                           | Severity | Governing Source      |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | --------------------- |
| VAL-121 | Exactly one of `cron`, `interval`, `calendar` MUST be non-null; the field matching `trigger_type` MUST be set and the other two MUST be null.                                                  | Blocking | Scheduler Contract §4 |
| VAL-122 | `cron`, when set, MUST be a valid 5- or 6-field cron expression.                                                                                                                               | Blocking | Schema constraint     |
| VAL-123 | `interval.every` MUST be ≥ 1 and `interval.unit` MUST be one of `seconds`\|`minutes`\|`hours`\|`days`.                                                                                         | Blocking | Schema constraint     |
| VAL-124 | `timezone` MUST be present and MUST be a valid IANA timezone identifier.                                                                                                                       | Blocking | Constitution §16.2    |
| VAL-125 | `misfire_policy` MUST be one of `catch_up` or `skip_if_missed`.                                                                                                                                | Blocking | Constitution RULE-044 |
| VAL-126 | `job_name` MUST be unique per `tenant_scope` at publish time.                                                                                                                                  | Blocking | Constitution §6.1     |
| VAL-127 | `dependency.depends_on` MUST NOT reference this job's own `job_name`, nor form a cycle across the scheduled-job/workflow dependency graph.                                                     | Blocking | Scheduler Contract §4 |
| VAL-128 | `retry.max_attempts` MUST be an integer between 0 and 10 inclusive.                                                                                                                            | Blocking | Constitution RULE-049 |
| VAL-129 | `owner_ref.type` MUST be one of `agent` or `workflow`, and `owner_ref.id` MUST resolve to an existing Registry entry with `status = active` before this job's `state` transitions to `active`. | Blocking | Constitution §16.3    |
| VAL-130 | `missed_run_alert_policy` MUST be present and non-empty.                                                                                                                                       | Blocking | Constitution §16.3    |
| VAL-131 | `priority` MUST be an integer between 1 and 10 inclusive.                                                                                                                                      | Blocking | Schema constraint     |
| VAL-132 | `execution_sla` MUST be present, matching ISO 8601 duration pattern `^PT\d+[SM]$`, whenever `state = active`.                                                                                  | Blocking | Constitution §16.3    |
